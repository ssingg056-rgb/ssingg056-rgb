* **Image Recognition** — powered by ONNX classification models (`goldai.onnx`, `mobilenetv3_pokemon.onnx`)

### 🤖 [Mr.meow](https://github.com/ssingg056-rgb/mr.meow)

A Python-based bot featuring an integrated economy system, database management, conversation history tracking, and OpenRouter API integration.

* **Economy System:** In-game shop, balance tracking, and purchasing mechanics.
* **OpenRouter Integration:** Flexible AI model routing via `api_client.py`.
* **Database Driven:** Powered by MongoDB for persistent user and application data.
* **History Management:** Formatted conversation logs with automated timestamp handling.
